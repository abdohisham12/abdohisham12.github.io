# Abdelrahman Mahmoud — Portfolio

Static GitHub Pages portfolio for an aerospace-trained systems engineer working across aerospace systems, AI, embedded engineering, software products, and entrepreneurship.

## Stack

- Semantic HTML
- CSS with responsive layout and reduced-motion support
- Vanilla JavaScript for navigation and project filtering
- Curated static media under `assets/portfolio/`
- GitHub Pages deployment from `main`

## Local development

Run any static server from the repository root, for example:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Content structure

- `index.html` — homepage content, metadata, experience, projects, ventures, and contact
- `styles.css` — shared visual system and responsive layout
- `script.js` — mobile navigation and accessible project filters
- `assets/images/` — project covers and supplied project artwork
- `assets/portfolio/` — curated public portfolio evidence and résumé
- `assets/logos/` — source organization and project marks

## Deployment

Push the `main` branch to deploy through GitHub Pages. Before publishing new media, confirm it is public and does not contain proprietary company information.
